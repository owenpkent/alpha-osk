# Property-based tests (tests/test_property_*.py).  Generates adversarial

# example count and disables the .hypothesis example database, so a run

# Linting & formatting.  Pinned exactly, not floored: `ruff format --check`
# is a CI gate, and the formatter's output changes between releases, so a
# floating install would turn the Lint job red on a tree nobody edited and
# make `python check.py` disagree with CI depending on when you last
# upgraded.  Keep this in step with the pin in .github/workflows/ci.yml.
ruff==0.16.2
