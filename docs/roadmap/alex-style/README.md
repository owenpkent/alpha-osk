# Vendored alex-style tokens

`tokens.css` is copied verbatim from `alexchunlin/alex-style-guide` at commit
`d1f744f` (`web/tokens.css`), so the design pages in this folder do not depend
on a clone of that repository. Re-copy it rather than editing it here.

Pages that use it:

- `../dictation-speaking-indicator.html`: candidate "the mic hears you"
  animations for the dictation button, with the level normalisation they
  all need. Open the file locally; only the fonts load from the network.
