# Vendored okstudio-style tokens

`tokens.css` is copied verbatim from `owenpkent/okstudio-style` at commit
`6fc4df7` (`web/tokens.css`), so the design pages in this folder do not depend
on a clone of that repository. Re-copy it rather than editing it here.

okstudio-style is MIT licensed, and the licence asks that its copyright and
permission notice travel with copies. [`LICENSE`](LICENSE) beside this file
is that notice, byte for byte from the same commit. Re-copy it with the
stylesheet.

okstudio-style replaces alex-style for new pages (2026-11-03). The class and
file names are the same; the older pages beside this folder still link
`../alex-style/tokens.css` and are left as they were drawn.

Pages that use it:

- `../controller-layout.html`: where a game controller would live in the
  keyboard window, as four clickable replicas, for
  [`../NIMBUS_INTEGRATION.md`](../NIMBUS_INTEGRATION.md). Open the file
  locally; only the fonts load from the network.
