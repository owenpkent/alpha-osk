# AGENTS.md

The onboarding document and codebase map for this project is
[`CLAUDE.md`](CLAUDE.md). Read that file.

This file is a pointer rather than a copy on purpose. It began as a
byte-identical duplicate of `CLAUDE.md` with nothing keeping the two in
step, and a change that touched one had to remember the other. Parallel
copies of one fact drifting apart is the failure mode `CLAUDE.md` warns
about for sticky-modifier release, the prediction bar's padding and the
context tables, and the prescription there is the same every time: one
source, with every reader pointed at it.
